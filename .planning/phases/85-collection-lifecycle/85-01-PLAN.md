- `disposal_reason` is a pgEnum (matches the condition_grade / box_papers_status precedent), not text + CHECK.

- No CHECK tying disposal fields to status. D-04's null-on-exit rule is enforced in the Server Actions (85-05), which are the only write path.
- No backfill of disposal_date / sell_price from `divestments` (deferred per CONTEXT).
