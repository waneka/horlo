    - Counts per owned watch: A with 3 events, B with 1 → A count 3, B count 1.

    - Zero-wear rows sort A→Z among themselves and always after every row with count > 0.
    - Empty ownedWatches → [].
    - Does not mutate the ownedWatches array order.
    scopeWornTabWatches (watches: owned O1, owned O2, wishlist W1; eventWatchIds = {O1, W1}):
    - isOwner true (any collectionPublic) → ownedWatches [O1, O2], mapWatches [O1, O2, W1].
    - isOwner false, collectionPublic true → ownedWatches [O1, O2], mapWatches [O1, W1] (only watches referenced by visible events).
    - isOwner false, collectionPublic false → ownedWatches [O1] (owned AND referenced by a visible event), mapWatches [O1, W1].
    - isOwner false, collectionPublic false, eventWatchIds empty → ownedWatches [], mapWatches [].
    - Preserves input order in both outputs.
